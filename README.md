# Solutio Whisper - downloads

This repository holds only the built apps for Solutio Whisper.
The source code is private.

Download the newest version from the [Releases page](https://github.com/Jerm401/solutio-whisper-downloads/releases/latest).

## Windows

1. Download `SolutioWhisper-<version>.zip`.
2. Unzip it and run the installer inside.

## Mac (Apple Silicon: M1 or later)

1. Download `SolutioWhisper-<version>-mac.zip` and open it.
2. Drag **Solutio Whisper** into **Applications**.
3. Open the app. macOS blocks it the first time.
4. Open **System Settings > Privacy & Security** and click **Open Anyway**.
5. Allow the **Microphone** and **Accessibility** permissions when the app asks.
6. Click in a text field, press **Option+Space**, and speak.

After an update, open **System Settings > Privacy & Security > Accessibility**,
turn Solutio Whisper off, and then on again.
